A practical e-commerce application built with **Laravel 12** and **Livewire 3**, based on the Udemy course  
**“Laravel 12 & Livewire 3. E-commerce Development”** by Andrey Kudlay.

The project focuses on hands-on learning and demonstrates how to build a modern online store with a dynamic UI and minimal JavaScript.

---

## Tech Stack

- PHP 8.x
- Laravel 12
- Livewire 3
- Blade
- MySQL / PostgreSQL
- Tailwind CSS
- Alpine.js (minimal usage)

---

## Features

### Customer-facing functionality
- Product catalog with categories
- Multi-level category menu
- Shopping cart (add, remove, update quantity)
- Product filtering and sorting
- Pagination
- User registration and authentication
- User account area
- Order checkout flow

### Admin panel
- CRUD for product categories
- CRUD for products
- CRUD for users
- CRUD for orders
- CRUD for filters

All interactions are handled **asynchronously** via Livewire, without full page reloads.

---

## Project Goals

- Practice Laravel 12 in a real-world scenario
- Learn Livewire 3 for building reactive interfaces
- Build a complete e-commerce workflow
- Strengthen OOP and backend architecture skills
